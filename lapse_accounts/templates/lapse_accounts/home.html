PatentRef

PatentRef is a PatentsView-compatible API for US patents granted from 1976 on, refreshed every week from USPTO data. It is an independent service and is not affiliated with the USPTO.

Get a free key Try it without a key

Point your code at PatentRef

The same endpoints, the same q, f, s and o parameters and the same response shape. The base URL is {{ site }}/api/v1/, and every request sends your key in X-Api-Key.

R (the patentsview package)

library(patentsview)
Sys.setenv(PATENTSVIEW_API_KEY = "{{ placeholder }}")
assignInNamespace("get_base", function(endpoint) sprintf("{{ site }}/api/v1/%s/", endpoint), ns = "patentsview")

Python

import requests
BASE = "{{ site }}/api/v1/"
print(requests.get(BASE + "patent/", params={"q": '{"patent_id":"10905426"}'}, headers={"X-Api-Key": "{{ placeholder }}"}).json())

{{ placeholder }} stands for your key. A free key allows {{ monthly }} requests a month and {{ per_minute }} a minute.
