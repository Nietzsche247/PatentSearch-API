# PatentSearch API 2.1.0 - Text Endpoints added
## Long text data notes
- The PatentSearch API now contains four new endpoints for long text data: brf_sum_text, claims, draw_desc_text and detail_desc text.
- These endpoints are currently in beta phase. i.e. please expect the structure and dataset included to change over the next few releases
  - Currently, only 2023 data is available. Over the next few release, we'd be backfilling older data few years at a time. You can track the status on this [page](/docs/docs/Search%20API/TextEndpointStatus)
- Please see [Endpoint Dictionary](/docs/docs/Search%20API/EndpointDictionary#brief-summary-text)
