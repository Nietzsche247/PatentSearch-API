# PatentSearch API 2.3.2

## Endpoint Data Dictionary Page
The endpoint and field details previously located at the end of the main [API Reference Page](/docs/docs/Search%20API/SearchAPIReference)
has been relocated to a [more detailed Data Dictionary Page](/docs/docs/Search%20API/EndpointDictionary)

## Data Use License added to Documentation
The [Creative Commons Attribution 4.0 license](https://creativecommons.org/licenses/by/4.0/),
which was already advertised as applying to PatentsView Data accessed via bulk download files,
is now explicitly applied to Data retrieved via the PatentSearch API as well.
